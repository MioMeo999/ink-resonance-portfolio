# Ink & Resonance

An independent portfolio website for Lijun Zhang, a Guzheng artist, researcher, and cultural connector based in Leeds.

The site brings together:

- artistic practice and biography
- the Sonic Belonging research project
- a complete archive of performances, workshops, and community activity
- performance videos
- media coverage from CCTV, People’s Daily, and CGTN
- interactive social QR codes

## Run locally

```bash
npm install
npm run dev
```

Then open [http://localhost:3000](http://localhost:3000).

## Production build

```bash
npm run build
npm start
```

## Technology

Next.js, React, TypeScript, CSS Modules, and Lucide icons.
